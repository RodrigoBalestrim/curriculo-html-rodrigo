# Currículo HTML — Rodrigo Balestrim

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `curriculo-rodrigo-html`.
3. Dê dois cliques em `index.html`.

## Como gerar PDF
1. Abra o currículo no navegador.
2. Clique em **Save as PDF**.
3. Escolha **Salvar como PDF** na janela de impressão.
4. Ative a opção **Gráficos de plano de fundo** para preservar as cores.

Os links de e-mail, telefone, portfólio, GitHub, LinkedIn, Behance e projeto Prazo Certo são clicáveis.
