# Rodrigo Balestrim — HTML Resume & Portfolio

A responsive, bilingual resume built with HTML, CSS, and JavaScript. It presents my front-end development skills, education, certifications, and featured projects in a clean layout optimized for both screens and PDF export.

## Highlights

- Responsive layout for desktop, tablet, and mobile
- English and Brazilian Portuguese versions
- Featured project cards with technologies and direct links
- Clickable email, WhatsApp, portfolio, GitHub, LinkedIn, and Behance contacts
- Print-ready A4 styling for professional PDF export
- No frameworks or build tools required

## Run Locally

Clone the repository:

```bash
git clone https://github.com/RodrigoBalestrim/curriculo-html-rodrigo.git
cd curriculo-html-rodrigo
```

Open one of these files in your browser:

- `index.html` — English version
- `index-ptbr.html` — Brazilian Portuguese version

## Export as PDF

1. Open the preferred resume version in your browser.
2. Click **Save as PDF**.
3. Select **Save as PDF** in the print dialog.
4. Enable **Background graphics** to preserve the complete design.
